private ASan/UBSan library. `cargo test --workspace` ran successfully through
unit and equivalence tests, but the existing global trybuild harness reported
two **unrelated snapshot text mismatches** among 175 fixtures:
`intfloat_mut_handle_sent_past_value.rs` and `intreadwrite_view_sent_past_bytes.rs`.
Both still reject the illegal program with the expected E0597; the installed

The remaining runtime suites and doctests are run with only that global
`compile_fail` harness excluded. This workset's four compile-fail doctests are
not excluded, and are separately verified by rustdoc.

Cargo does not automatically pass the sanitizer linker flags to rustdoc. An
initial unconfigured doctest run could not link the sanitizer symbols; it was
rerun with the correct flags. Runtime workspace tests (excluding only the global
snapshot harness), the workset's Rust-and-C ASan/UBSan tests and TSan tests all
passed. The full `cargo test --workspace` limitation remains only the two
pre-existing trybuild text mismatches, retained in `trybuild-mismatches.txt`.

Correctly configured sanitized rustdoc passed all 120 crate doctests (91 normal
and 29 compile-fail), including the four new owner/borrow rejection cases.
`cargo test -p libavutil-sys` passed after regeneration against the private
sanitized library. `cargo clippy --workspace --all-targets` additionally checks
integration-test safety comments; its one new test-only comment placement was
corrected without changing behavior.

Final configured `cargo test --workspace -- --skip compile_fail` passed all
runtime suites and doctests; `cargo clippy --workspace --all-targets` passed.
The four new compile-fail doctests independently reject all illegal borrow
paths. No sanitizer finding occurred in the worklist.
